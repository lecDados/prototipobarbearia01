# Prototipobarbearia01

crie um sistema de gestão para barbearia, deve ser um sistema limpo visualmente, organizado e com cores interativa. a tela inicial deve ser limpa saldando o usuário: Hello, Vanio Black! lembrando a stetyca do iPhone quando é iniciado, com cores parecidas.

no parte superior esquerda da tela, um menu com designer meio transparente simbolizando uma gota d'agua, ao abri tera: Dashboard, catalogo de serviços, carteira, funcionários, contas, estoque.

mantenha um designer moderno, estilo macOS. cores vibrantes que se mistura como degradar, com tons de rosa, roxo azul, etc.. fontes limpas..
